# Git

- Langkah 1: Ambil semua update terbaru dari repo ASLI

```
git fetch upstream
```

- Langkah 2: Merge update itu ke branch local kamu

```git merge upstream/master

```

- Langkah 3: Push ke repo GitHub KAMU supaya ikut terupdate

```git push origin main

```
